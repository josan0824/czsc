## 一、K 线包含处理（预处理）

在任何级别 K 线图上，标注前必须先做 **K 线包含处理**，这是所有后续计算的基础。

### 1.1 包含关系定义（第 62 课）

> **包含关系**：一根 K 线的高低点全部在相邻 K 线的高低点范围之内。

- 向上趋势中的包含：**高点取最高，低点也取最高**（向上合并）
- 向下趋势中的包含：**高点取最低，低点也取最低**（向下合并）

### 1.2 包含处理规则（第 65 课）

**步骤一**：判断走势方向

> 用向上还是向下合并的规则，取决于第一根 K 线与前一根（非包含关系）K 线的位置关系：
> - 如果第一根 K 线的高点 > 前一根的高点 → **向上趋势** → 取"高高"
> - 如果第一根 K 线的高点 < 前一根的高点 → **向下趋势** → 取"低低"

**步骤二**：合并包含 K 线

```
向上处理（取高高）：
  新K线高点 = max(高点1, 高点2)
  新K线低点 = max(低点1, 低点2)

向下处理（取低低）：
  新K线高点 = min(高点1, 高点2)
  新K线低点 = min(低点1, 低点2)
```

**步骤三**：递归处理

> 包含关系是**连续**的。处理完一对 K 线后，新生成的 K 线可能与下一根 K 线仍然存在包含关系，需要继续处理，直到不再存在包含关系为止。

**方向判断的连续性与递推原则**：
- 处理包含关系时，方向判断的参照 K 线是 **"向前看非包含"的 K 线**
- 即需要跳过已经包含的 K 线，以处理完包含后的新 K 线作为参照来判断方向

### 1.3 包含处理范例

```
原始 K 线序列（向上趋势中）：
  ① 高10, 低5
  ② 高9, 低6   ← 包含在①内
  ③ 高12, 低8

处理①②（向上→取高高）：
  新②: 高=10, 低=6

新②与③（向上→取高高）：
  最终: 高=12, 低=8
```

## 二、分型（第 62-65 课）

分型是缠论最基本的构造单元，所有笔、线段、中枢都建立在分型之上。

### 2.1 顶分型定义

> **顶分型**：三根 K 线（经过包含处理后），中间 K 线的**高点最高**，且中间 K 线的**低点最高**。

```
      ③(高)
  ②(高)    ①(高)
  ①(低)    ③(低)
      ②(低)

条件：K2.high > K1.high 且 K2.high > K3.high
      K2.low > K1.low  且 K2.low > K3.low
```

### 2.2 底分型定义

> **底分型**：三根 K 线（经过包含处理后），中间 K 线的**低点最低**，且中间 K 线的**高点最低**。

```
  ①(高)    ③(高)
      ②(高)
      ②(低)
  ①(低)    ③(低)

条件：K2.low < K1.low 且 K2.low < K3.low
      K2.high < K1.high 且 K2.high < K3.high
```

### 2.3 分型确认的严格规则（第 63 课）

> 分型的确认不能只看三根单独的 K 线，必须**经过包含处理之后**再看。

> 分型的确认，还需要以下一根非包含关系的 K 线来**确认分型的有效性**。

**确认规则**：
- **顶分型确认**：顶分型出现后，下一根 K 线的**收盘价**位于顶分型第一根 K 线的**高点之下**
- **底分型确认**：底分型出现后，下一根 K 线的**收盘价**位于底分型第一根 K 线的**低点之上**

### 2.4 分型的强弱判别

**顶分型强弱**（第 64 课）：
- **最强**：第三根 K 线为长阴，直接跌破第一根 K 线的**最低点**
- **较强**：第三根 K 线跌破第一根 K 线的**最低点**但非长阴
- **中等**：第三根 K 线跌破第一根 K 线的**最高点**但不破最低
- **较弱**：第三根 K 线在第二根 K 线的区间内收盘

**底分型强弱**（与之相反）：
- **最强**：第三根 K 线为长阳，直接升破第一根 K 线的**最高点**
- **较强**：第三根 K 线升破第一根 K 线的**最高点**
- **中等**：第三根 K 线升破第一根 K 线的**最低点**但不破最高
- **较弱**：第三根 K 线在第二根 K 线的区间内收盘

### 2.5 分型到笔的过渡规则

> 相邻的顶分型与底分型之间构成一笔。但并非所有相邻分型都能构成笔。

**笔成立的条件**（第 62 课）：
1. 顶底分型之间**必须间隔至少 1 根独立 K 线**（即不能共用 K 线）
2. 顶底分型必须**交替出现**（不能顶顶相邻或底底相邻）
3. 分型必须经过包含处理后确认

## 三、笔（第 62 课、第 65 课）

笔是连接相邻顶底分型的直线段，是次一级别的走势单元。

### 3.1 笔的定义

> **向上笔**：从底分型开始，到顶分型结束。
> **向下笔**：从顶分型开始，到底分型结束。

```
向上笔：底分型 → ... → 顶分型  （价格上升）
向下笔：顶分型 → ... → 底分型  （价格下降）
```

### 3.2 笔的成立条件

**严格条件**（第 62 课）：
1. **顶底之间必须有独立 K 线**：顶分型的最高 K 线（中间那根）与底分型的最低 K 线（中间那根）之间，至少有一根不属于顶底分型的 K 线（在 1 分钟图上至少要间隔 5-6 根，日线上至少 4 根）
2. **顶底必须交替**：一个底分型之后必须是顶分型，反之亦然。不能出现连续两个底分型或连续两个顶分型
3. **分型必须确认**：分型必须有后续 K 线确认才是有效的分型

### 3.3 笔的延伸

> 笔一旦形成，在未被新笔破坏之前，将持续延伸。即：
> - **向上笔延伸**：新的高点不断创出新高
> - **向下笔延伸**：新的低点不断创出新低

**笔的结束标志**：当出现**反向的分型**（即顶分型后出现底分型，或底分型后出现顶分型），且该反向分型经过确认后，当前笔结束，新笔开始。

### 3.4 笔的破坏（第 65 课）

> **笔被破坏**：当新出现的反向笔已经至少覆盖了原笔最后一段反向运动，即可认为原笔被破坏。

实际上，笔的破坏就是向**新笔的形成**，即一旦新笔的底分型（或顶分型）确认，原笔即被破坏。

### 3.5 笔的算法实现

```
function find_pens(k_lines):
    1. 对 K 线进行包含处理
    2. 扫描所有 K 线，找到经过确认的顶分型和底分型
    3. 按以下规则连接分型成笔：
       a. 从第一个有效底分型开始
       b. 寻找下一个有效顶分型
       c. 如果顶底之间有独立 K 线，形成一笔
       d. 再从该顶分型开始，寻找下一个有效底分型
       e. 重复直到处理完所有 K 线
    4. 特殊处理：
       - 如果连续出现多个顶分型，取最高的那个
       - 如果连续出现多个底分型，取最低的那个
```

## 四、线段（第 62-65 课）

线段由至少三笔构成，是走势分解的基本单位。

### 4.1 线段的定义

> **线段**：至少由三笔构成，且这三笔必须有重叠部分。线段的方向由第一笔的方向决定。

```
上升线段：↑ ↓ ↑（向上笔 + 向下笔 + 向上笔，且后一笔的高点高于前一笔）
下降线段：↓ ↑ ↓（向下笔 + 向上笔 + 向下笔，且后一笔的低点低于前一笔）
```

### 4.2 线段的构成

> **特征序列**（第 65 课）：
> - 对于上升线段，其特征序列由**向下笔**构成
> - 对于下降线段，其特征序列由**向上笔**构成
> - 特征序列中的每一笔称为一个**特征元素**

### 4.3 线段的破坏（第 65 课）

> **缠中说禅线段分解定理**：线段被破坏，当且仅当至少被有重叠部分的连续三笔的其中一笔破坏。

**破坏的两种方式**：

**方式一：笔破坏（第一笔即破坏）**
> 新线段的第一笔（反向笔）直接破坏了原线段的最后一个特征元素，即该反向笔的幅度超过了原线段最后一笔的幅度。

**方式二：线段破坏标准形式**
> 新线段的前三笔（特征序列的前三笔）需要有重叠部分，并且新线段的方向与原线段相反。

```
线段破坏判定流程：
  1. 判断是否有反向笔出现
  2. 如果有反向笔，判断该反向笔是否构成"笔破坏"
  3. 如果构成笔破坏，等待后续走势确认
  4. 如果后续走势形成与反向笔同向的新线段，则原线段被破坏
```

### 4.4 特殊情形处理

**线段的延伸**：
- 线段在一个方向上会不断延伸，直到被反向线段破坏为止
- 线段延伸中，特征序列会出现包含关系

**线段的特征序列包含处理**：
> 线段的特征序列也需要进行包含处理，规则与 K 线的包含处理类似，但方向判断不同：
> - 如果前一个特征元素是向上的，则包含处理取"高高"（向上合并）
> - 如果前一个特征元素是向下的，则包含处理取"低低"（向下合并）

**顶底分型在笔和线段中的区别**：
> 分型在笔级别中可以直接用于构造笔；在线段级别中，分型用于构造特征序列，从而判断线段的破坏。

## 五、中枢（第 17 课）

中枢是缠论的核心概念，所有买卖点都围绕中枢展开。

### 5.1 中枢定义

> **缠中说禅走势中枢**：某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分。

在日线级别（笔为次级别）上的近似定义：
> **日线中枢**：至少连续三笔的重叠部分。

### 5.2 中枢区间计算

```
中枢区间 = [ZD, ZG]

ZD (中枢下沿) = max(三个次级别走势的最低点)
ZG (中枢上沿) = min(三个次级别走势的最高点)

GG (中枢最高点) = max(三个次级别走势的最高点)
DD (中枢最低点) = min(三个次级别走势的最低点)
```

其中，三个次级别走势按顺序为：
- 走势 A：低点 d1, 高点 g1
- 走势 B：低点 d2, 高点 g2
- 走势 C：低点 d3, 高点 g3

```
ZD = max(d1, d2, d3)  // 三个走势的低点中的最大值
ZG = min(g1, g2, g3)  // 三个走势的高点中的最小值
```

**中枢存在的条件**：`ZD ≤ ZG`

### 5.3 中枢的三种状态

**1. 中枢延伸（第 18 课）**
> 围绕中枢的震荡一直在中枢区间 [ZD, ZG] 内，没有突破 ZG 或跌破 ZD。

```
延伸条件：所有后续的震荡高点 ≤ ZG，且震荡低点 ≥ ZD
```

**2. 中枢扩张（第 18 课）**
> 围绕两个同级别中枢的波动产生重叠，形成一个更高级别的中枢。

```
中枢 A 的波动区间 = [DD_A, GG_A]
中枢 B 的波动区间 = [DD_B, GG_B]
扩张条件：[DD_A, GG_A] 与 [DD_B, GG_B] 有重叠
         且中枢 A 与中枢 B 的区间 [ZD_A, ZG_A] 与 [ZD_B, ZG_B] 不重叠
```

**3. 中枢新生（第 18 课）**
> 新的中枢完全在旧中枢上方（上涨趋势中）或下方（下跌趋势中），且两个中枢的区间没有重叠。

```
上涨趋势新生条件：DD_B > GG_A（中枢 B 的最低点 > 中枢 A 的最高点）
下跌趋势新生条件：GG_B < DD_A（中枢 B 的最高点 < 中枢 A 的最低点）
```

### 5.4 中枢破坏（第 20 课）

> **缠中说禅走势中枢定理三**：某级别"缠中说禅走势中枢"的破坏，当且仅当一个次级别走势离开该"缠中说禅走势中枢"后，其后的次级别回抽走势不重新回到该中枢内。

```
中枢向上破坏的条件（第三类买点）：
  1. 有一个次级别走势向上离开中枢（突破 ZG）
  2. 然后有一个次级别走势回试
  3. 回试的低点不跌破 ZG

中枢向下破坏的条件（第三类卖点）：
  1. 有一个次级别走势向下离开中枢（跌破 ZD）
  2. 然后有一个次级别走势回抽
  3. 回抽的高点不升破 ZD
```

## 六、标注算法整体流程

```
输入：原始 K 线数据（OHLCV）
  │
  ├─ Step 1: K 线包含处理
  │    └─ 递归合并包含 K 线，直到没有包含关系
  │
  ├─ Step 2: 识别分型
  │    ├─ 扫描三连 K 线，识别顶分型和底分型
  │    └─ 用后续 K 线确认分型的有效性
  │
  ├─ Step 3: 构造笔
  │    ├─ 找到第一个有效分型（顶或底）
  │    ├─ 交替寻找反向分型
  │    ├─ 检查顶底之间是否有独立 K 线
  │    └─ 连接分型形成笔，在图上标注"笔"
  │
  ├─ Step 4: 构造线段
  │    ├─ 找到连续三笔（↑↓↑ 或 ↓↑↓）
  │    ├─ 检查三笔是否有重叠
  │    └─ 标注线段方向和端点
  │
  └─ Step 5: 构造中枢
       ├─ 找到连续三段重叠区域
       ├─ 计算 ZD, ZG, DD, GG
       └─ 标注中枢区间 [ZD, ZG] 和扩展/新生状态
```

### 标注图例建议

```
K 线图标注符号：
  ────  笔（连接顶底分型的线段）
  ─ ─ ─ 线段（趋势线）
  ▓▓▓▓  中枢区间（在 ZD 与 ZG 之间的矩形区域）
  ▲     顶分型标识
  ▼     底分型标识
  T     趋势线标记（上涨 ↑ / 下跌 ↓）
  B     买点标记（B1/B2/B3）
  S     卖点标记（S1/S2/S3）
```

```
  上涨笔 / 上升线段：红色
  下跌笔 / 下降线段：绿色
  中枢区间：灰色半透明矩形区域
  顶分型标记：蓝色 ▼（顶部向下箭头）

  第二类买卖点：黄色圆点
  第三类买卖点：紫色圆点
```

## 七、关键原文参考

> 以下为原文核心段落摘录：

**关于包含处理**（第 65 课）：
> "用[di,gi]记号第i根K线的最低和最高构成的区间，当向上时，顺次n个包含关系的K线组，等价于[maxdi,maxgi]的区间对应的K线，也就是说，这n个K线，可以用最低点最高的K线区间和最高点最高的K线区间来表示。"

**关于分型**（第 62 课）：
> "顶分型：第二K线高点是相邻三K线高点中最高的，而低点也是相邻三K线低点中最高的。底分型：第二K线低点是相邻三K线低点中最低的，而高点也是相邻三K线高点中最低的。顶分型的最高点叫该分型的顶，底分型的最低点叫该分型的底。"

**关于笔**（第 62 课）：
> "本ID想了想，计算了一下能量，发现，把这笔的成立条件稍微放松一下，也是不影响整个理论的，毕竟线段的大前提是至少三笔。新笔的定义：只要顶分型和底分型之间，有独立的一根K线，就可以成笔。"

**关于线段**（第 65 课）：
> "线段被破坏，当且仅当至少被有重叠部分的连续三笔的其中一笔破坏。而只要构成有重叠部分的前三笔，那么必然会形成一线段，换言之，线段破坏的充要条件，就是被另一个线段破坏。"

**关于中枢**（第 17 课）：
> "缠中说禅走势中枢：某级别走势类型中，被至少三个连续次级别走势类型所重叠的部分。换言之，缠中说禅走势中枢就是至少三个连续次级别走势类型重叠部分所构成。"
